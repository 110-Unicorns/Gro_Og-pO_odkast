# Format d'episodi

Cada carpeta `episodis/NNN-slug/` porta quatre fitxers. Cap no executa res.

## `00-meta.md`
Títol, número, data, durada estimada, etiquetes, estat (esborrany / gravat / publicat).

## `01-guio.md`
Estructura de l'episodi: blocs, transicions, cues d'àudio. Guia de gravació, no text final.

## `02-lletra.md`
El que es diu o es canta. Lletra / transcript net.

## `03-notes-terra.md`
Notes fora del micro: context, terra, decisions. El que queda clavat i no es recita a l'Àgora.

- CHAT ≠ CODE ≠ ACTION ≠ SHELL
